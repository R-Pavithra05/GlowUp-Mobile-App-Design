GlowUp - Mobile Appointment Booking App
#Project Overview
GlowUp is a mobile-first appointment booking application designed for a local salon business to improve user experience, simplify booking, and reduce dependency on manual scheduling methods.
The application provides users with a modern and intuitive way to browse services, select time slots, and confirm appointments seamlessly through a mobile interface.

#Problem Statement
Many local salon businesses rely on phone calls and manual registers for booking appointments. This leads to:
missed appointments
double bookings
slow communication
lack of structured scheduling
This project solves these issues by introducing a streamlined and digital booking experience.

#Objective
The objective of this project is to design a mobile application that:
simplifies the booking process
reduces manual effort
improves scheduling efficiency
enhances overall user experience
Target Users
Students and working professionals
Users who prefer quick mobile booking
Customers looking for salon services without calling
Users seeking fast and convenient appointment scheduling
Screens Designed
Splash Screen
Login Screen
Home Screen
Service Selection Screen
Time Slot Booking Screen
Appointment Confirmation Screen

#UX Decisions
Mobile-First Design for better accessibility
Linear Booking Flow for ease of use
Touch-Friendly UI for better interaction
Clear Visual Hierarchy for guided navigation
Minimal Design Approach to reduce clutter

Conversion-Focused Features
Quick “Book Now” actions
Minimal booking steps
Clear pricing and service visibility
Interactive time slot selection
Simple confirmation flow

#Conclusion
The GlowUp mobile app design transforms a traditional manual booking system into a structured and user-friendly digital experience.
