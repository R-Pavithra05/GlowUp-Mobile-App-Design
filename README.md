# GlowUp - Mobile Appointment Booking App
## Project Overview
GlowUp is a mobile-first salon appointment booking app designed to simplify the scheduling process and improve user experience for local beauty services.
The project focuses on clean UI, structured booking flow, minimal steps, and a smooth mobile experience for quick and efficient appointment scheduling.
## Problem Statement
Many local salon businesses rely on:
Phone calls for booking
WhatsApp messages
Manual registers
This leads to:
Missed appointments
Double bookings
Delayed communication
Unstructured scheduling
This app solves these issues using a streamlined digital booking system.
## Objective
Simplify appointment booking
Reduce manual effort
Improve scheduling efficiency
Create a clean mobile UI
Provide a fast and seamless booking experience
## Target Users
Students and working professionals
Users who prefer quick mobile booking
Customers avoiding phone-based booking
Users looking for convenience and speed
